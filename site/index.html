Como instalar

Dois comandos e o ambiente inteiro é instalado. Requer Windows com PowerShell 5.1 e Git. Não precisa de administrador. Prefere só algumas skills? Escolha na seção Skills antes de instalar.

01

Requisitos

Windows com PowerShell 5.1 (nativo), Git instalado e a ferramenta alvo: Claude Code e/ou opencode.

02

Clonar

Sem Git? Use o botão Baixar ZIP acima e extraia a pasta.

git clone https://github.com/diego-ruas/maleta.dev.git
03

Instalar

Instala Claude Code e opencode de uma vez. Se claude/skills-selection.txt existir na pasta, instala só as skills marcadas:

powershell -ExecutionPolicy Bypass -File scripts/install.ps1
04

Reiniciar

Reinicie o Claude Code ou o opencode para carregar skills, plugins e MCP. Só uma ferramenta? Rode claude/install.ps1 ou opencode/install.ps1.

Perguntas frequentes

Preciso instalar as duas ferramentas?

Não. O scripts/install.ps1 instala tudo, mas cada pasta tem o próprio install.ps1 — rode só o da ferramenta que você usa. O repo também tem uma pasta antigravity/, mas ela é um placeholder: hoje o instalador dela não copia nada.

As skills são seguras? Como são auditadas?

Sim. Todas as 82 skills são provenientes de repositórios upstream oficiais ou de alta reputação (Anthropic, Cloudflare, Obra/Superpowers, Emil Kowalski, Shadcn, Vercel) e passam por auditoria automatizada com o SkillSpector, scanner de segurança especializado para agentes de IA que inspeciona injeções de prompt, regras YARA, integridade de AST e permissões MCP. O relatório detalhado de conformidade está disponível em SKILLSPECTOR_REPORT.md na raiz do repositório.

Meus dados são enviados para algum lugar?

Não. O repositório é instalação somente: os scripts copiam arquivos para a sua máquina e nada do seu ambiente é enviado de volta.

Como atualizo depois de instalar?

Rode git pull na pasta clonada e execute o instalador da ferramenta de novo — ele recopia skills e configurações por cima. settings.json e ~/.claude.json são mesclados e ganham um .pre-install.bak antes; já o ~/.claude/CLAUDE.md é sobrescrito sem backup. Nada é removido: tirar uma skill do repo não a apaga de ~/.claude/skills/.

Sem Git na máquina?

Use o botão Baixar ZIP no topo da página, extraia a pasta e rode o instalador como no passo 03.

Precisa de administrador?

Não. Os scripts só escrevem em %USERPROFILE% e %LOCALAPPDATA%. O -ExecutionPolicy Bypass serve apenas para o Windows aceitar rodar um script não assinado — não altera a política da máquina.

Qual é a licença?

O wrapper do repositório (scripts, docs, configurações) é MIT. As skills de terceiros dentro de claude/skills/ pertencem aos seus autores e mantêm as próprias licenças.

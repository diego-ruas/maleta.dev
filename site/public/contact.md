# Contact — Maleta.dev

## Bugs and skill suggestions

Primary channel: <https://github.com/diego-ruas/maleta.dev/issues>. Use it for install failures, outdated skills, broken catalog links, or to propose a new skill. For install issues, include the operating system, the assistant version (Claude Code or Codex) and the exact command that was run.

## Code contributions

Pull requests are welcome in the same repository. Third-party skills in the catalog are faithful copies of upstream artifacts and are not edited locally — fixes to them belong upstream, and Maleta.dev syncs the updated version afterwards. Changes to the site and the install scripts can be proposed directly.

## Email

For anything that does not fit a public issue — licensing, content removal, press, or a question involving sensitive data — write to diegodruas@proton.me. The project is maintained by one person, in Portuguese and English.

## Security

Do not open a public issue for vulnerabilities in the install scripts or the site. Email diegodruas@proton.me with details and reproduction steps. The scripts run with the user's permissions and write to local configuration directories, so reports in this area are prioritized.

## For agents

Read <https://maleta.dev/llms.txt> for canonical install commands and appropriate use cases.
